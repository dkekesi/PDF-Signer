Rendszerkövetelmények

A PDF Signer for Tungsten Capture használatához az alábbi munkaállomás-konfigurációk javasoltak:

Hardverkövetelmények

Minimális:

  • Intel Core i3 1,8 GHz CPU;
  • 2 GB RAM;
  • 300 MB szabad háttértár.

Javasolt:

  • Intel Core i5 3,0 GHz CPU;
  • 8 GB RAM (6 GB szabad memória az alkalmazás indulásakor);
  • SATA3 vagy NVMe SSD;
  • 15 GB szabad háttértár.

Szoftverkövetelmények

A PDF Signer for Tungsten Capture az alábbi operációs rendszereken üzemel:

  • Windows Server 2022;
  • Windows Server 2025;
  • Windows 11 (24H2 vagy újabb).

Figyelem! Többszáz MB-os fájlok hitelesítéséhez mindenképpen 64-bites operációs rendszer szükséges a javasolt hardverkonfiguráció mellett!

.NET Framework követelmény:

  • .NET Framework 4.8 vagy újabb.

A PDF Signer for Tungsten Capture az alábbi Tungsten Capture rendszerek tetszőleges service pack-jén és fix pack-jén üzemel:

  • Tungsten Capture 11.2.
