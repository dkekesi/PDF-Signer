PDF Signer for Tungsten Capture telepítése

A telepítőkészlet tartalma

A PDF Signer for Tungsten Capture rendszer telepítője az alábbi fájlokat és mappákat tartalmazza:

  • a rendszer MSI telepítőcsomagja (PDFSignerSetup.msi)
  • a PDF Signer for Tungsten Capture rendszer licencfájlja
  • követelmények mappa (Prerequisites mappa)
    • .NET Framework 4.6.1 angol nyelvi verzió (NDP461-KB3102436-x86-x64-AllOS-ENU.exe)

A telepítés menete

Követelmények telepítése

.NET FrameWork 4.6.1 telepítése

Amennyiben még nincs telepítve, úgy a PDF Signer for Tungsten Capture telepítőkészlet Prerequisites mappájából telepítsük fel a .NET Framework 4.6.1-es verzióját. Mindenhol fogadjuk el az alapértelmezett beállításokat.

A PDF Signer for Tungsten Capture installálása

Figyelem! A PDF Signer for Tungsten Capture csak olyan munkaállomásra vagy szervere telepíthető, amelyen a Tungsten Capture kliens előzőleg telepítve lett!

A követelmények telepítését követően jelentkezzünk be helyi adminisztrátori jogokkal rendelkező felhasználóval, és indítsuk el a telepítőt a PDFSignerSetup.msi programmal.

A megjelenő ablakban olvassuk el, majd fogadjuk el a licencszerződést az I accept the terms in the License Agreement jelölőnégyzet bejelölésével.

Az Install gombra kattintva megtörténik a rendszer telepítése. A telepítőben semmilyen beállításra nincs lehetőség, mivel a program automatikusan a Tungsten Capture alkalmazás megfelelő könyvtárába települ.

A Finish gomb megnyomására a telepítő bezárul.

A PDF Signer for Tungsten Capture licencfájl telepítése

A licencfájl telepítése attól függ, hogy a Tungsten Capture rendszert hálózatos (Server) vagy egymunkaállomásos (Standalone) módban telepítettük.

Licencfájl telepítés hálózatos (Server) installáció esetén

Hozzunk létre a Kofax fájlmegosztáson (alapértelmezés szerint \\kofaxszervernév\CaptureSV) belül egy új mappát PDFSigner néven. A kapott PDFSigner.license fájlt másoljuk ebbe a mappába.

Licencfájl telepítés egymunkaállomásos (Standalone) installáció esetén

Másoljuk a PDFSigner.license fájlt a Tungsten Capture Bin mappájába.
